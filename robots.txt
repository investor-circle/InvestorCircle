# myinvestorcircle.com
#
# Public ideas and the stock pages that aggregate them are meant to be found.
# Member PROFILES are not: that was a deliberate decision, revisited once
# (see CLAUDE.md) to let a shared profile link render a correct preview card
# (name, avatar, ICI score) — /investor/:username now has real
# server-rendered content for a signed-out visitor or a link-preview bot
# (web-public/app/(pages)/investor/[username]/, same middleware.js
# cookie-routing scheme as /security/:symbol and /idea/:id), not just the
# plain SPA shell index.html serves everyone else (see its own
# canonical-tag comment). "Linkable" and "indexable" are different
# decisions — only the first changed. The page's own generateMetadata also
# sets robots: noindex as defense-in-depth, but the rule below remains the
# load-bearing one: it's what actually keeps Googlebot from crawling the
# path at all, not just declining to index what it finds.

User-agent: *
Allow: /

# Not indexable, and not to be crawled.
Disallow: /investor/

# /search itself is crawlable (its own <meta name="robots"> is
# noindex,follow — see web-public/app/search/page.jsx) so its outbound
# links to /security/:symbol and /idea/:id get followed without the search
# results page itself being indexed as a destination.
